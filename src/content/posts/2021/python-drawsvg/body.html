drawCsvとは

Githubに詳しく書いてある。いい感じにベクター形式の画像を作ったりアニメーションも作成できる。

使い方

Githubに詳しい解説があるので、そのままインストールしたがうまく使えない。Macでcairoのインストールがうまくできていないらしい。いろいろ頑張って最終的には以下のエラー。

Original OSError: dlopen() failed to load a library: cairo / cairo-2 / cairo-gobject-2 / cairo.so.2

あきらめて、Google Colaboratoryを使うとpip installだけで実行できた。

参考サイト

  • pip3 install drawSvg
