コマンド

ローカルにあるイメージのリスト

docker images

イメージのダウンロード

$ docker pull image_name(:tag)

コンテナの起動

$ docker run hello-world

コンテナの中に入る

$ docker run -it ubuntu bash

コンテナ一覧

$ docker ps -a

使用していないイメージ・コンテナの削除

$ docker image prune -a
$ docker container prune

cpuやmemoryの使用率の確認

docker stats

Dockerfileからイメージの作成

$ docker build ./path/to/Dockerfile

-t オプションでイメージ名を指定。

Dockerfileの作成

単純なDockerfile

FROM ubuntu
RUN echo "You run docker build"
CMD echo "You run docker run"

コンテナの中に入り、必要なファイルのインストールなどを行い、うまくいけばDockerfileの RUNに 記述していく。
