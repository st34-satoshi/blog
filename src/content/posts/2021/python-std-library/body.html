inspect 呼び出しもとの情報を取得する

デバッグに便利。呼び出しもとの関数名やファイル名を取得できる。その他にも活動中のオブジェクトの様々な情報を取得できるらしい。詳しくはドキュメントで。inspect — 活動中のオブジェクトの情報を取得する — Python 3.9.0 ドキュメント

import inspect

def who_does_call_me():
  print(inspect.stack()[1].filename)
