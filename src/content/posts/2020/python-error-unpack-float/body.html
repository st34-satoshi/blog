pythonでTypeError: cannot unpack non-iterable float objectが出た時の対処法

  1. コード
  2. 原因
  3. 解決方法
  4. 終わりに
  5. 関連記事

コード

def add(a, b):
    return a + b

s, t = add(1.0, 2.0)

原因

floatをs, tに代入しようとしている。

解決方法

def add(a, b):
    return a + b

s = add(1.0, 2.0)

終わりに

pythonで関数の返り値の型がよくわかっていないときに発生するエラーの一つ。
