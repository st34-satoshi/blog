ブログを書くときなど、webページのタイトルを簡単にコピーしたい。そこで、Create Linkという拡張機能を使用してタイトルをコピーできるようにし、ショートカットを割り当てた。

    1. Chromeに拡張機能のCreate Linkをインストール
  2. ショートカットの割り当て
  3. 参考
  4. 関連記事

やること

Chromeに拡張機能のCreate Linkをインストール

こちらからインストールできる。「Create Link – Chrome ウェブストア」

ショートカットの割り当て

Create Linkの設定で割り当てることが可能。

Default Formatで自分が使用したいフォーマットを決め、ショートカットを作成する。ショートカットはcurrent tab in default formatでショートカットを入力すれば良い。In Chromeを選択する。
