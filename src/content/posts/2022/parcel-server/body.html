やること

parcelのインストール

  • $ npm init -y
  • $ npm install parcel-bundler

htmlの作成

index.html

<!DOCTYPE html>
<html>
<head>
<title>Hello Parcel</title>
</head>
<body>
<script src="./index.js"></script>
</body>
</html>

index.js

alert('hello parcel')

実行

package.jsonにscriptを追加

  "scripts":{
    "dev": "parcel index.html"
  }
  • $ npm run dev
  • http://localhost:1234/ にアクセスする
