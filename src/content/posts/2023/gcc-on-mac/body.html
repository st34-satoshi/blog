  1. brew install gcc
  2. brew upgrade

シンボリックリンクやエイリアスをつける

% which gcc
/usr/bin/gcc

which gccで/usr/bin/gccが参照されるのでhomebrewでインストールした方を参照したい。

シンボリックインクでも良いが今回はエイリアスにしてみる。

atcoderコマンドでg++が実行される。g++のバージョンは適切なバージョンにする。

alias atcoder=/opt/homebrew/bin/g++-13
