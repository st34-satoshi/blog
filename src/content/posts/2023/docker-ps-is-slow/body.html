docker psがとても遅くなって10分経っても終わらなくなった。

  1. 原因
  2. 学び
  3. docker pruneも気をつけよう
  4. diskの使用状況を調べる

原因

調査すると、cronで毎時間実行しているタスクで、docker run website-monitoring python main.py があった。

–rmオプションをつけていないかった。これが原因でコンテナが毎日24個ずつ増えていき、半年経ったらとんでもないことになっていた。

学び

–rmオプションはちゃんとつける

docker pruneも気をつけよう

docker psが遅かったのでdocker image pruneやdocker container pruneをやった。

起動していないimageを削除するとcronでdocker run imageを実行できなくなる。

何も考えずにpruneするとまずいこともあるんだなぁ。。。

diskの使用状況を調べる

dockerでどれくらいdisk容量を使っているかを調べるのはdocker system dfが便利。使いすぎている箇所を見つけてpruneする。
